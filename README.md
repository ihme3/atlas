# ATLAS — учебный сайт

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере — сайт работает без установки.
3. Для публикации на GitHub Pages загрузите `index.html`, `style.css` и `app.js` в корень репозитория.
4. В GitHub откройте **Settings → Pages**, выберите публикацию из ветки `main` и папку `/ (root)`, затем сохраните.

## Что есть внутри
- Учебные зоны по истории, обществознанию и русскому языку (задания ЕГЭ №1–26).
- Добавление собственных тем.
- Таймер фокуса с паузой, сбросом и сохранением завершённых/частичных занятий.
- Квест из пяти вопросов с результатом и рекомендованной длительностью следующего занятия.
- Мини-игры: память, сапёр, числовые ряды и линия метро.
- XP, уровни, история и статистика по предметам.
- Экспорт прогресса в JSON.

## Хранение данных
Прогресс хранится в `localStorage` браузера на конкретном устройстве. Это локальный сайт без регистрации и облачной синхронизации. Кнопка со стрелкой в левом верхнем меню позволяет сбросить данные.
